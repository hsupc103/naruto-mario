## 🎮 遊戲特色與核心機制

1. **二頭身 Q 版動漫鳴人＆雙型態五官細膩刻畫**
   - 採用二頭身 Nendoroid 動漫比例與 3/4 正面雙眼視角，清晰呈現木葉護額、雙側金髮鬢角、湛藍大眼、雙頰 **6 道招牌鬍鬚印記**與露齒笑容。
   - **雙血條系統（`HP 100 / 100`）**：左上角 HUD 與遊戲畫面上方鳴人頭頂皆即時顯示生命值血條，支援鳥居檢查點重生與 3 條命 Game Over 挑戰。
2. **🍄 吃查克拉香菇 → 發射「螺旋丸光彈」＋回復 40 HP**
   - 撞擊「`?`」方塊吃下查克拉香菇後，按 `J` 或 `Z` 可向前直線發射高速旋轉的**螺旋丸光彈**。
   - **依敵人強度決定所需光彈數**：
     - 音忍下忍斥候：**1 發**螺旋丸擊倒
     - 霧隱中忍護衛：**2 發**螺旋丸擊倒
     - 穢土上忍暗部：**3～5 發**螺旋丸擊倒
     - 咒印巨型通靈獸：**5～7 發**螺旋丸擊倒
3. **⭐ 吃無敵星星 → 變身「九尾查克拉鳴人」＋ 3 顆超大玉尾獸彈**
   - 吃下無敵星星後，鳴人全身披上金紅九尾查克拉外衣、雙眼化為鮮紅狐狸豎瞳並露出尖銳九尾虎牙，背後展開 9 條搖曳狐尾，立即回滿 `100 HP` 並獲得 **3 顆尾獸彈（`尾獸彈 × 3`）**。
   - **3.0 秒集氣尾獸彈（`K` / `X` 或點擊畫面「💥 發射尾獸彈」按鈕）**：
     - 集氣滿 **3.0 秒**後自動轟出黑紫陽陰查克拉交織的**超大玉尾獸彈**：
       1. **全畫面雜魚一擊必殺**：瞬間湮滅當前螢幕內所有一般與菁英敵人。
       2. **頭目決戰重創**：對關卡 Boss 造成巨額傷害，但每個關卡頭目皆需 **2～3 發尾獸彈**（或搭配螺旋丸連續射擊）才能徹底擊破！
4. **🗺️ 三大華麗忍界關卡（每關約 2 分鐘路程抵達 Boss 決戰）**
   - **STAGE 1：木葉森林與終末之谷** — 頭目：**桃地再不斬・霧隱鬼人**（水遁・大瀑布之術）
   - **STAGE 2：大蛇丸紅月音忍要塞** — 頭目：**大蛇丸・八岐禁術之主**（潛影蛇手・萬蛇羅之陣）
   - **STAGE 3：曉之雷雲・雨隱神域決戰** — 頭目：**佩恩天道・六道神羅天徵**（神羅天徵・超萬象天引）

## ⌨️ 操作說明

| 按鍵 / 按鈕 | 動作說明 |
| :--- | :--- |
| `A` `D` 或 `◀` `▶` | 左右奔跑移動 |
| `W` / `Space` / `▲` | 忍躍（支援二段跳躍與踩擊敵人） |
| `J` / `Z` / `Enter` | 直線發射**螺旋丸光彈**（需先吃查克拉香菇） |
| `K` / `X` / `Shift` 或點擊 `💥 發射尾獸彈` | 啟動 **3.0 秒集氣**並自動發射**超大玉尾獸彈**（需吃無敵星星變身九尾，每次限 3 顆） |
